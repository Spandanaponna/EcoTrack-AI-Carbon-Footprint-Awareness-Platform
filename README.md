# EcoTrack AI

## Chosen Vertical
Carbon Footprint Awareness Platform

## Problem Statement
Many individuals are unaware of the environmental impact of their daily activities. This project helps users estimate their carbon footprint and receive actionable recommendations.

## Features
- Carbon footprint calculator
- Carbon score meter
- Transport mode adjustment
- Monthly CO2e estimate
- Travel, electricity, and food breakdown
- Personalized sustainability recommendations
- Responsive UI
- Accessibility-friendly design

## Tech Stack
- HTML
- CSS
- JavaScript

## Approach
The application calculates a simplified monthly carbon estimate based on daily travel, transport mode, electricity usage, and diet preference. It converts that estimate into a carbon score and displays an impact level, category breakdown, and customized recommendations.

## Assumptions
Emission values are simplified estimates for awareness purposes.

## How To Run
1. Clone repository
2. Open index.html
3. Start calculating your footprint
